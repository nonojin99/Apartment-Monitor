# 7억 타겟 단지 모니터 (1년 추적용)

6개 지역(동탄 / 수원 망포·영통 / 용인 수지·처인이동 / 평택 고덕지제)에서
**예산 6.0~8.5억 · 전용 84㎡** 에 드는 단지를 추려, 기대 상승여력 높은 순으로 보여줍니다.
※ 최고가 추적이 아니라 **'살 수 있는 단지 중 가치 좋은 것'** 을 찾는 도구입니다.

## 빠른 시작 (키 없이 지금 바로)

```powershell
pip install playwright
python seed.py          # 단지별 샘플 데이터 (최초 1회)
python dashboard.py     # dashboard.html 생성 + 브라우저 자동 오픈
```
※ 차트는 CDN(Chart.js)을 쓰므로 **인터넷 연결 상태**에서 열어야 보입니다.
  (인터넷이 없으면 단지 목록·표는 나오고 차트 자리에 안내문구가 표시됩니다.)

## 화면 구성

1. **예산 타겟존 시각화** — 초록 띠가 내 예산존(6.0~8.5억). 막대=현 시세(중앙값), 마름모=중립 기대가격.
2. **관심 단지 목록** — 여력순 정렬. ★를 눌러 1년 추적 watchlist 등록(세션 한정).
3. **단지별 실거래 추이** — 1년 누적하면 이 선으로 매수 타이밍을 잡습니다.
4. **참고: 예산 밖 단지** — 지금은 벗어났지만 조정 시 진입 가능할 수 있는 단지.

## 핵심 설계: '최고가'가 아니라 '중앙값 + 예산필터'

- 현 시세 = 단지별 **최근 실거래 중앙값**(최고가 추종 방지)
- `config.TARGET_BUDGET = (60000, 85000)` 범위에 드는 단지만 표시
- 정렬 = 예산 안에서 **기대 상승여력(중립) 높은 순**
- ⚠️ 같은 지역 단지는 여력%가 같게 보입니다 — 기대 상승률은 **지역 호재**(교통·팹·미분양)에서 나오기 때문.
  같은 지역·같은 예산이면 **현 시세가 낮은 단지 = 같은 호재를 더 싸게 사는 것**이라 유리.

## 주간 모니터링 루틴 (5분)

1. rt.molit.go.kr에서 시군구별 월별 CSV 받기 → 파일명을 `동탄_2026.csv`처럼 **지역명_** 으로 시작하게 → `data/`에 넣기 → `python collect.py csv`
2. 호가 입력(선택): `python collect.py manual` → `동탄,시범한빛마을,84,20,75000`
3. 호재 단계 갱신: `config.py`의 `REGION_STATE` 수정 (예: 동탄 트램 '계획'→'착공')
4. `python dashboard.py` 재생성

## 나중에 자동수집 (API 키 발급 후)

공공데이터포털 "아파트 매매 실거래가" 신청(무료) → `config.py`의 `API_KEY` 입력 →
`python collect.py api 202501 202606`

## 예산/평형/지역 바꾸기

전부 `config.py`에서:
- 예산: `TARGET_BUDGET = (60000, 85000)`  (만원)
- 평형: `TARGET_AREA = (80, 90)`  (전용 ㎡)
- 지역 추가/삭제: `REGIONS` 딕셔너리

## ⚠️ 한계

- **기대가격은 예측이 아니라 가설**입니다. 과거 패턴의 코드화일 뿐 미래를 보장하지 않습니다.
- 매물 호가 자동수집은 약관 문제로 미구현(수동 입력). 실거래만 자동.
- watchlist(★)는 새로고침하면 초기화됩니다(브라우저 저장 미사용). 1년 추적은 DB에 데이터가 쌓이는 것으로 유지됩니다.
- 샘플 단지명/가격은 검증용 예시이며 실제 시세와 다릅니다. 실데이터로 교체하세요.

## 파일

| 파일 | 역할 |
|---|---|
| `config.py` | 지역·예산·평형·가중치 + **호재 상태(주간 갱신)** |
| `collect.py` | CSV 적재 / API 수집 / 호가 입력 |
| `expect.py` | 단지별 기대가격 엔진 (단독 실행 시 콘솔 요약) |
| `dashboard.py` | dashboard.html 생성 |
| `seed.py` | 단지별 샘플 (최초 테스트) |
